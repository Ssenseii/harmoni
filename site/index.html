HARMONI

HARMONI is a desktop application that downloads music from Spotify playlist exports and from YouTube, using yt-dlp. It writes metadata to the files and includes tools for managing a music library.

It runs on Windows, macOS and Linux, has a graphical interface and a command-line mode, and is free and open source under the project license. Playlists are imported from Exportify CSV files, so no Spotify API setup is needed. Connecting your own Spotify account through the Spotify API is also supported, but it is optional and requires creating a Spotify developer app first (see the Spotify setup guide).

Quick start

  1. Download and run HARMONI (above).
  2. Go to exportify.net, log in with Spotify, export playlists as CSV.
  3. Drag the CSV into HARMONI.

Thanks

HARMONI is built on the work of two projects. Thank you to the yt-dlp team, whose downloader does the actual fetching, and to the FFmpeg team, whose tools handle audio conversion.
